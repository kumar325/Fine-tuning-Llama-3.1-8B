#Fine-tuning-Llama-3.1-8B
This project fine-tunes the Llama AI model using Low-Rank Adaptation (LoRA), a parameter-efficient technique that improves model performance while keeping resource usage minimal. The goal was to train the model to generate accurate and concise titles for given questions. LoRA fine-tuning was applied across multiple training epochs, which significantly improved the model's accuracy at predicting appropriate titles. After training, the model was deployed using NVIDIA Inference Microservices (NIM) to speed up inference times and make it more practical for real-world use. Fine-tuning large language models is usually resource-intensive, but using parameter-efficient methods like LoRA makes it feasible to customize powerful models without needing massive compute resources.
